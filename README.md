# Atividade-4-Desafio2-Cadastro-de-Produtos-com-Valida-o
Atividade 4: Sistema de Cadastro de Produtos com Validação em PHP e MySQL. Formulário para inserção de nome e preço, com validação de dados (nome não vazio e preço positivo) antes da inserção no banco de dados. Desenvolvido para prática de backend e segurança de dados.
